## 🔗 איך הקישורים עובדים:

### מדף הבית לגלריה:
כשלוחצים על קטגוריה בדף הבית:
1. המערכת שומרת את שם הקטגוריה ב-localStorage
2. המשתמש מועבר ל-`gallery.html`
3. הגלריה קוראת את הקטגוריה ומציגה אותה אוטומטית
4. הכפתור המתאים מסומן כ-active

### קישורים ישירים:
ניתן לשתף קישור ישיר לקטגוריה:
- `gallery.html#villas` → יציג ישירות את הוילות
- `gallery.html#zimmer` → יציג ישירות את הצימרים
- וכן הלאה...
